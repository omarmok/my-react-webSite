- **New Architecture Opportunity (found 2026-07-16, supersedes the old `_oldButtons.scss` mixin-duplication entry above):** `css/helpers/_mixins.scss` (line ~347) independently defines its own `@mixin moi-btn-size-vars`, numerically equivalent in default values to `_buttons.scss`'s version (both resolve to the same effective px values, one in `rem`, one in `px`) but with a *different, stronger 3-selector cascade pattern* (`&[data-size], &.btn[data-size], &[class*='moi-btn--'][data-size]` vs. `_buttons.scss`'s single `&[data-size]`). Because `_oldButtons.scss` and `_buttons.scss` both do `@use "../helpers" as *;`, and `helpers` also exposes this same-named mixin, Sass cannot resolve `@include moi-btn-size-vars;` in either file without a local definition to disambiguate — confirmed empirically: removing `_oldButtons.scss`'s local copy produces a hard compile error, "This mixin is available from multiple global modules." This means `_buttons.scss` *also* needs its own local copy for the same reason (not because it duplicates `_oldButtons.scss`, but because it must shadow `helpers/_mixins.scss`). Benefit of resolving: a true single source of truth for this mixin, avoiding 3-way silent drift. Risk: `helpers/_mixins.scss`'s version has an intentionally *stronger* cascade (its own comment says "Stronger selectors to win the cascade") — unifying could change specificity-dependent behavior for any consumer relying on that extra strength; also unclear which of the 2-3 consumers of `helpers/_mixins.scss`'s copy exist beyond what was checked in this pass. Affects: `css/common/_buttons.scss`, `css/common/_oldButtons.scss`, `css/helpers/_mixins.scss`. Suggested approach if approved: pick one canonical definition (likely the stronger `helpers/_mixins.scss` cascade, since it was deliberately written to "win"), remove the other two, and switch `_buttons.scss`/`_oldButtons.scss` to consume it via a namespaced `@use "../helpers" as helpers;` + `helpers.moi-btn-size-vars` call (avoiding the `as *` ambiguity permanently) — not implemented, Architecture Opportunity only.
