Date Picker

Hijri / Gregorian date (and date-time) picker attached to a text field, with the project calendar look and per-rule field classes.

المكوّن: منتقي التاريخ الملفات: _datetimepicker.scss, hijriDatePickerConfig.js آخر تحديث: 25 أكتوبر 2026

Purpose & when to use

The date picker lets the user pick a Hijri or Gregorian date from a calendar attached to a text field. It is the plugin bootstrap-hijri-datetimepicker (Bootstrap datetimepicker with a Hijri calendar), configured once in js/hijriDatePickerConfig.js and styled by css/components/_datetimepicker.scss to match the Figma «Datetime & Picker» page.

  • Use it for any date field: incident date, birth date, document expiry, range filters.
  • Hijri is the default; the footer switch toggles هجري / ميلادي.
  • For time only, use the native input type="time" with .input-with-icon-time.

Variants (field classes)

Pick the class that matches the business rule; the limits are set in js/hijriDatePickerConfig.js.

.hijri-date-inputYYYY-MM-DD1901 → 2070Any date
.hijri-date-input-pastYYYY-MM-DDUp to todayIncident date, birth date
.hijri-date-input-futureYYYY-MM-DDFrom todayAppointments, expiry

Usage rules

  • Always pair the field with a visible label; the placeholder is not a label.
  • Use the variant class for limits instead of validating after submit.
  • Keep the stored value Gregorian (format) and show Hijri (hijriFormat) unless the service says otherwise.
  • Do not restyle the widget per page; _datepicker.scss is deprecated and no longer compiled.

Accessibility & RTL

  • Typing the date in the field must stay possible; the calendar is a helper, not the only input.
  • Footer buttons and arrows show a visible focus ring (:focus-visible).
  • Day cells are 40×40 — keep them; they are the touch target.
  • RTL is on (isRTL: true, locale: 'ar-SA'): previous points right, next points left; numbers and dates stay LTR inside the field.

Developer API

Include the plugin CSS, jQuery, the plugin and the shared configuration, then call hijriRender() once the fields are in the DOM (call it again after rendering new fields).

<link href="./css/bootstrap-datetimepicker.css" rel="stylesheet" />
<link href="./css/main.css" rel="stylesheet" />

<label class="form-label required" for="caseDate">تاريخ وقوع الحالة</label>
<div class="position-relative">
  <input autocomplete="off" type="text" id="caseDate"
         class="form-control hijri-date-input-past input-with-icon">
</div>

<script src="./js/jquery-3.6.0.min.js"></script>
<script src="./js/bootstrap-hijri-datetimepicker.min.js"></script>
<script src="./js/hijriDatePickerConfig.js"></script>
<script>$(function () { hijriRender(); });</script>

Gregorian-only field

$('.my-gregorian-date').hijriDatePicker({
  locale: 'ar-sa', format: 'YYYY-MM-DD', hijri: false, showSwitcher: false,
