Overview

The button system follows the Figma «Buttons» component (the source). Write .moi-btn with exactly one style modifier .moi-btn--* and a size data-size. Styles live in css/common/_buttons.scss (disabled fallback in _buttonBase.scss). Full example page: moi-buttons.html.

PartMarkupNotes
Button<button class="moi-btn moi-btn--{Style}">One base class and exactly one style modifier
Sizedata-size="sm|md|lg|xl"Use md by default in screens
Lead icon<svg> before the labelShows on the right of the label (RTL)
Trail icon<svg> after the labelShows on the left of the label (RTL)
Icon onlydata-icon-only="true" + aria-labelAt least a 44×44 touch area
Loadingdata-state="loading" + svg.moi-btn__loaderIn place of the lead icon

Base · solid · outline: .moi-btn--Neutral, .moi-btn--Neutral--solid, .moi-btn--Neutral--outline.

States

State is interaction only; never use it to show business status.

StateHowLook
DefaultThe button as writtenStyle colours
Hover / PressedAutomatic on pointer hover and pressSee the colour table
Focus-visible:focus-visible2px ring, black at 40%, keyboard focus only
Disableddisabled / aria-disabled="true"Neutral-200 background, Neutral-400 border and text for every style
Loadingdata-state="loading" + aria-busy="true"Default colours, spinning loading-03 icon, clicks blocked

Usage rules

  • One Primary (or Save / Send) per area for the main action.
  • Error = reject or destructive actions; Warning = caution.
  • Use the presets for Save, Cancel, Send and Save later instead of writing them again.
  • Text style for low-emphasis actions only.
  • In a footer, the main action comes first (right-most in RTL).
  • Do not add new styles, colours or sizes; ask the design system owner.

Accessibility

  • Use a real button element with type set.
  • Icon-only buttons need aria-label; icons are aria-hidden.
  • Keyboard focus shows a visible 2px ring.
  • Loading buttons set aria-busy="true".
  • The spinner stops when the user prefers reduced motion.
  • Touch area is at least 44×44.
