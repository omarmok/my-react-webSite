Business Components / Map

Map

Mapbox location picker / viewer with layers, coordinates and landmark details.

المكوّن: الخريطة الملفات: _mapDesign.scss آخر تحديث: 25 أكتوبر 2026

Purpose & when to use

Location picker and viewer built on Mapbox GL: a titled map with a layers menu, coordinates / landmark details and a reset action. Code: .new-custommap (and .imsmap) in css/components/_mapDesign.scss. Figma: Map (page ❖ Business Components / Map) — the details type is the approved one (11 Oct).

Anatomy

PartClassRole
Root.new-custommapCard that holds the map block
Title bar.new-custommap--titleTitle + map-type dropdown
Map area.new-custommap--mapContainerMapbox canvas
Layers menu__menumap · .checkedmenuCheckbox list of layers
Location details__locationDetails · .Longitude · .landmarkCoordinates, landmark chips (pill badges / treeselect values)
Reset__resetLocationClears the pin

Usage rules

  • Always show the coordinates and the landmark next to the map; the map alone is not accessible.
  • In details pages the map is view-only (no reset, no picking).
