Timeline

Timeline displays a sequence of events or records in chronological order. Two patterns currently exist in the project: an alternating left/right timeline (.timeline), and a date-badge-plus-content-card timeline (.iq-timeline2 and .Itinerary).

المكوّن: الخط الزمني الملف: css/components/_timeline.scss آخر تحديث: 16 يوليو 2026

Purpose & when to use

Use Timeline to present a sequence of events or records in chronological order — for example, an activity log on a case, an approval trail, or a list of visits/inspections. This is currently a static HTML/SCSS display pattern, not a JavaScript-driven interactive component.

  • Use a semantic list (ul/ol) as the events container where possible; the current SCSS does not enforce this.
  • For each event, include the date and a short status text; do not rely on color alone to distinguish the current/completed event.

Anatomy

Pattern one (.timeline) shows alternating cards left/right around a central vertical line.

Element Class Description
Root .timeline Root container; draws the central vertical line.
Event container .timelinecontainer One event's container, 50% width of the timeline.
Side .right / .left Sets whether the event appears on the right or left of the central line.
Card .content The event's content card, with an arrow pointing to the central line.
Date text .timeDate Date text inside the card.

Pattern two (.iq-timeline2 and .Itinerary) shows a circular date badge connected by a vertical line, with a separate content card per event.

Element Class Description
List item .iq-timeline2 li One list item per event, no bullet marker.
Date badge .content-date Circular badge (60×60) showing the date, connected by a vertical line.
Badge variant .bg-Date / .bg-Date-currant .bg-Date for a white badge background; .bg-Date-currant highlights the current event in the primary color.
Content block .content-block The event's content card (white background, rounded corners, soft shadow).
Number (Itinerary) .numric Small circular number badge (20×20) used in the Itinerary pattern.

Usage rules

  • Do not mix the two patterns (.timeline and .iq-timeline2) within the same list — pick the one that fits the context.
  • Use .bg-Date-currant to highlight only the current event, not more than one per list.
  • Keep the same content shape (date + status text) for every event, even when the text length varies.

Accessibility Guidance

  • Wrap the event list in a semantic list element (ul or ol) where possible, so screen readers can announce the item count.
  • Give avatar images (.writenBy img) a descriptive alt, or an empty alt if purely decorative.
  • Do not rely on color alone (.bg-Date-currant) to mark the current event; add supporting text such as "current" next to the badge.

Developer API

The code samples below reflect the real structure in css/components/_timeline.scss.

.timeline pattern (left/right)

<div class="timeline">
  <div class="timelinecontainer right">
    <div class="content">
      <h2>عنوان الحدث</h2>
      <span class="timeDate">12 يوليو 2026</span>
    </div>
  </div>
  <div class="timelinecontainer left">
    <div class="content">
      <h2>عنوان الحدث التالي</h2>
      <span class="timeDate">14 يوليو 2026</span>
    </div>
  </div>
</div>
