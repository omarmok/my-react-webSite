Components / Timeline

Timeline

Timeline displays a sequence of events or records in chronological order. The component is .moi-timeline, matching the Figma design: a date circle, an event card, an optional tag, attachments and replies, and a reply button that opens the reply modal.

المكوّن: الخط الزمني الملف: css/components/_timeline.scss آخر تحديث: 25 أكتوبر 2026

Purpose & when to use

Matches the Figma design (timeline, timeline-atom, timeline-reply, timeline-attachment). It shows a history of events in order: a date circle and an event card built on the Card component, with an optional tag, attachments, replies, and a reply button that opens the reply modal.

  • Styles: css/components/_timeline.scss (the .moi-timeline section at the end of the file).
  • Full example page: timeLine/moi-timeline.html.
  • Built on existing components: Card (.moi-card), Tag (.moi-tag), Buttons (.moi-btn), Modal (.modal) and .form-control.

Anatomy

Element Class Description
Container .moi-timeline Root section: header + bordered body.
Header .moi-timeline__header __title __header-icon Title «المتابعات» with its icon.
Body / list .moi-timeline__body .moi-timeline__list Bordered body holding an ordered list of events.
Event .moi-timeline__item One event (Figma timeline-atom). States via modifiers.
Connector .moi-timeline__connector Vertical line through the date circle. Omit it to hide the line.
Date circle .moi-timeline__date __date-day __date-month 60×60 circle: day + month.
Event card .moi-card.moi-timeline__card Reuses the Card component (moi-card + __header / __title-group / __title).
Card header .moi-timeline__card-header __heading __event-title Title (+ optional tag) and date/time.
Date / time .moi-timeline__meta __meta-item __icon Date and time with calendar / clock icons.
Content .moi-timeline__content __description __creator(-label / -name) Description + «بواسطة» creator.
Attachments .moi-timeline__attachments __attachment(-info / -name / -meta / -view) File chips; the whole chip is a link.
Replies .moi-timeline__replies __reply __reply-header __reply-sender(-name) __reply-date __reply-text Replies to this event, inside its card.
Replies bar .moi-timeline__replies-bar __replies-count Replies count + «الرد على الرسالة» button.

States

State Class Look When to use
Default (no modifier) White circle, grey header. Any past event.
Active .moi-timeline__item--active Primary circle, green border and header. The current event — one per list.
Error .moi-timeline__item--error Error-600 circle, red border and header. Rejected / failed step.
Warning .moi-timeline__item--warning Warning-600 circle, amber border and header. Needs attention / delayed.
Info .moi-timeline__item--info Info-600 circle, blue border and header. Informational event.

Usage rules

  • Use .moi-timeline for every history of events.
  • Order events chronologically inside an ol; only one event may be --active.
  • Replies to an event go inside that event's card, not as separate list items.
  • The reply button opens the reply modal, not a new page.
  • Show attachments as file chips; do not use a table inside the event.
  • The tag shows status or direction only (وارد / صادر); it is not an action.
  • Keep dates and numbers left-to-right inside Arabic text (time or bdi).

Accessibility Guidance

  • The container is a section labelled by its title; events are in an ol, so screen readers announce the count.
  • The connector and the icons are hidden from screen readers (aria-hidden="true").
  • Each file chip is a link with an aria-label («عرض …») and a visible focus ring.
  • Do not rely on colour alone for the state; say it in the event title or in a tag.
  • The reply textarea has a linked label and is required.
