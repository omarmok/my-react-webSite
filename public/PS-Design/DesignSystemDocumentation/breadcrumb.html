Breadcrumb

Home › parent › current page, under the top bar of every inner page.

Component: BreadcrumbFiles: _breadcrumb.scss (.moi-breadcrumb)Last updated: November 2, 2026

Purpose & when to use

Aligned with the improved Figma breadcrumb: separators belong to their item, text is 14px, the current page is SemiBold, long labels truncate and the layout never wraps.

Figma: «• Breadcrumb»Code: .moi-breadcrumbLegacy .breadcrumb-container kept
  • Shows where the page sits in the service hierarchy: Home › parent › current page. Place it under the top bar of every inner page.
  • Use 2 to 4 levels. For deeper paths keep the first, the parent and the current page and use the Additional levels slot only for what the user needs.
  • The current page is plain text, not a link.

Usage rules

Do

  • Put the full name in title on every label.
  • Mark the current page with aria-current="page".
  • Give the home icon an aria-label.

Don't

  • Do not add a separator manually or as a text character.
  • Do not let the breadcrumb wrap or scroll horizontally.
  • Do not link the current page.

Accessibility

  • Wrap in <nav aria-label> with an ordered list. The label follows the page language.
  • The separator is decorative (CSS only) so screen readers do not announce it.
  • Links show a 2px focus ring ($Primary-400) on keyboard focus.

Developer API

The legacy .breadcrumb-container .breadcrumb markup in _common.scss still works for existing screens. Use .moi-breadcrumb for new work; rebuild main.css after pulling.

HTML

<nav aria-label="Breadcrumb">
  <ol class="moi-breadcrumb">
    <li class="moi-breadcrumb__item moi-breadcrumb__home">
      <a href="/" aria-label="Home"><svg viewBox="0 0 24 24" aria-hidden="true">…</svg></a>
    </li>
    <li class="moi-breadcrumb__item"><a href="/services" title="Services">Services</a></li>
    <li class="moi-breadcrumb__item" aria-current="page"><span title="Service details">Service details</span></li>
  </ol>
</nav>

<!-- 16px text -->
<ol class="moi-breadcrumb moi-breadcrumb--lg">…</ol>

<!-- RTL: put dir="rtl" on the page or on the nav; the separator mirrors automatically -->
