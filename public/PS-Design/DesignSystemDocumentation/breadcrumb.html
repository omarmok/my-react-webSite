Breadcrumb

Home › parent › current page, under the navbar of every inner page.

المكوّن: مسار التنقل الملفات: _common.scss (.breadcrumb-container) آخر تحديث: 25 أكتوبر 2026

Purpose & when to use

Shows where the page sits: Home › parent › current page. Code: Bootstrap .breadcrumb inside .breadcrumb-container (styled in css/common/_common.scss). Figma: Breadcrumb with Show parent, Show current page, Show additional levels, Current page, Parent label.

Anatomy

PartCodeSpec
Home.homebreadHouse icon before the label
Link item.breadcrumb-item afont-sm-500, $Neutral-600
Separator.breadcrumb-item + .breadcrumb-item::beforebread-arrow icon
Current page.breadcrumb-item.active · .currant__page$Neutral-800 / $Neutral-900, aria-current="page"

Note: css/common/_breadcrumb.scss (.moi-breadcrumb) is not compiled — do not use those classes.

Usage rules

  • Every inner page shows the breadcrumb under the navbar; the current page is not a link.
  • Use the same names as the sidebar and page titles.

Developer API

<div class="breadcrumb-container">
  <nav aria-label="مسار التنقل">
    <ol class="breadcrumb">
      <li class="breadcrumb-item homebread"><a href="/">الرئيسية</a></li>
      <li class="breadcrumb-item"><a href="./requests.html">طلبات التحري</a></li>
      <li class="breadcrumb-item active" aria-current="page"><span class="currant__page">تفاصيل الطلب</span></li>
    </ol>
  </nav>
</div>
