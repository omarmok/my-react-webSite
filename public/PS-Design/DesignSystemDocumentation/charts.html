Charts

Donut chart and chart colors for dashboard counts.

Component: ChartsFiles: _charts.scssLast updated: November 2, 2026

Overview

Figma: chart colorsCode: legacy pie in _charts.scss

Charts summarize counts by status on dashboards. The repository ships one chart style, the donut used on the cases dashboard (css/components/_charts.scss); the slices are drawn by the page script, not by a shared component. Figma defines a chart palette in the Themes variables (group Charts) and a Progress Bar color. The legend badges in code still use hard-coded colors (#7DCD18, #ff8103, #0652c2), so the palette below is the target.

Accessibility

  • Never rely on color alone: print the value and the status name in the legend.
  • Give the chart a text alternative (role="img" + aria-label) or a data table.
  • Use at most six segments; group the rest as «Other».

RTL notes

  • The donut itself is not mirrored; the legend order and badge positions follow the page direction.
  • Digits use the page numeral style consistently (do not mix Arabic-Indic and Western digits in one chart).
