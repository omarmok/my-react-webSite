Sweet Alert

Short system dialogs and toasts built on SweetAlert2 with the project theme — results, confirmations, one-field input, toast and loader.

المكوّن: التنبيهات المنبثقة الملفات: sweet-alert.css, sweet-alert.html آخر تحديث: 25 أكتوبر 2026

Purpose & when to use

SweetAlert2 is the project dialog for short system messages: a result (success / error), a confirmation before an action, a one-field input, a toast, or a blocking loader. The project theme in css/sweet-alert.css gives it the same shell as the project modal: a Neutral-100 header bar, IBM Plex Sans Arabic, project buttons and system icons.

  • Use it for one decision or one message. Anything with more than one field, a table, or several steps belongs in the project Modal (Composable) or a page.
  • Use the toast for non-blocking feedback that needs no action (saved draft, data refreshed). It closes by itself.
  • Do not use SweetAlert for page-level status that must stay visible — use the Notification (alert.html).

Usage rules

Do

  • Write the title as the question or the result («حذف المركبة؟», «تم الحفظ بنجاح»).
  • Name the confirm button with the action verb («حذف», «إرسال», «إسناد»), not «نعم».
  • Use moi-swal--danger and focusCancel: true for destructive actions.
  • Use the shared MoiSwal mixin so texts and buttons stay consistent.

Don’t

  • Don’t stack a SweetAlert on top of a Modal or another SweetAlert.
  • Don’t put forms with several fields in it — use the Modal.
  • Don’t pass inline colours or confirmButtonColor; the theme styles the buttons.
  • Don’t use a toast for errors that need an action.

Accessibility & RTL

  • SweetAlert2 traps focus and restores it on close; keep returnFocus on.
  • Buttons show the project focus ring (2px inner + 4px outer) on :focus-visible.
  • Toasts are announced politely and must not carry the only copy of an error.
  • RTL: the page sets dir="rtl"; the title and labels align to the start side, the confirm button sits on the start side (right).
  • The toast opens at position: 'top-end' — top-left in RTL.

Developer API

Load order: SweetAlert2 CSS → css/main.css → css/sweet-alert.css. Reference page: PS-Design/sweet-alert.html.

Shared setup (MoiSwal)

const MoiSwal = Swal.mixin({
  confirmButtonText: 'تأكيد',
  cancelButtonText: 'إلغاء',
  denyButtonText: 'عدم الحفظ'
});

// Result
MoiSwal.fire({ icon: 'success', title: 'تم الحفظ بنجاح', text: 'تم حفظ بيانات الحادث.', confirmButtonText: 'حسناً' });

// Destructive confirm
const r = await MoiSwal.fire({
  icon: 'warning', title: 'حذف المركبة؟', text: 'سيتم حذف المركبة وكل بياناتها، ولا يمكن التراجع.',
  showCancelButton: true, confirmButtonText: 'حذف', focusCancel: true,
  customClass: { popup: 'moi-swal--danger' }
});

// One-field input
MoiSwal.fire({ title: 'رفض الطلب', input: 'textarea', inputLabel: 'سبب الرفض',
  inputPlaceholder: 'أدخل سبب الرفض', showCancelButton: true, confirmButtonText: 'رفض',
  customClass: { popup: 'moi-swal--danger' } });

// Toast
MoiSwal.fire({ toast: true, position: 'top-end', icon: 'success', title: 'تم حفظ المسودة',
  showConfirmButton: false, timer: 3000, timerProgressBar: true });

// Loader (project loader markup inside the alert)
MoiSwal.fire({ html: loaderMarkup, showConfirmButton: false, allowOutsideClick: false,
  customClass: { popup: 'moi-swal--loader' } });
