Components / Dropdown

Dropdown

Native select for simple lists; vue-treeselect for searchable, multi and tree selection with the Text Input states.

المكوّن: القائمة المنسدلة الملفات: _vue-treeselect.scss آخر تحديث: 28 أكتوبر 2026

Purpose & when to use

Single, multi and tree selection fields. Simple lists use the native select.form-select (see Text Fields). Searchable, multi or hierarchical lists use vue-treeselect, styled by css/common/_vue-treeselect.scss to match the Figma input type=select / multi-select and the Dropdown page.
