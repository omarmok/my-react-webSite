Avatar

A picture, initials or icon that represents a person or entity.

Overview

Figma: definedCode: no shared class yet

An avatar is a small picture, initials or icon that represents a person or entity. The component exists in Figma («Components / Avatar»: 42 variants, an Avatar Group and a presence indicator). The repository has no shared avatar class yet; only page-level mentions in _layout.scss and _identity-access.scss. Per the Public API rules a new class needs the owner's approval, so the previews below only illustrate the Figma spec and are not shipped styles.

Code example (copy)

A reference implementation that matches the previews above. It is not shipped: copy it into your page until the owner approves a shared .moi-avatar API. Replace var(--neutral-*) with the system tokens in your build ($Neutral-200, $Neutral-300, $Neutral-700).

HTML

<!-- Image -->
<span class="avatar" data-size="48"><img src="photo.jpg" alt="أحمد محمد"></span>

<!-- Initials -->
<span class="avatar" data-size="48" aria-label="أحمد محمد">أم</span>

<!-- Icon -->
<span class="avatar" data-size="48" aria-hidden="true"><svg viewBox="0 0 24 24"><path d="…"/></svg></span>

<!-- Square (entities) -->
<span class="avatar avatar--square" data-size="48">وز</span>

<!-- Presence status: online | busy | mission | off -->
<span class="avatar-presence" data-status="online"><span class="avatar" data-size="40">أم</span></span>

<!-- Group -->
<span class="avatar-group">
  <span class="avatar" data-size="32">أم</span>
  <span class="avatar" data-size="32">سع</span>
  <span class="avatar" data-size="32">+3</span>
</span>

Accessibility

  • A photo needs alt text with the person's name; decorative avatars next to a visible name use alt="".
  • Presence must not rely on color alone: add a text or tooltip («online», «busy»).
  • Keep initials to two characters and make sure text and background pass contrast.

RTL notes

  • Stacked avatars overlap toward the start side and the presence dot sits at the inline-end corner, so both mirror in RTL.
  • Initials: use the first letter of the first and last name in the page language (two Arabic letters are not joined with a gap).

Do & Don't

Do

  • Provide alt text or an aria-label with the person name.
  • Use initials when there is no photo.

Don't

  • Do not stretch a photo; crop it to fill the circle.
  • Do not rely on the status color alone; add a text label where it matters.
