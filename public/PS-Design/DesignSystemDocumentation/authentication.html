Authentication

Confirm the identity of the attendees of a procedure.

Component: AuthenticationFiles: _userauthentication.scssLast updated: November 2, 2026

Overview

Figma: AuthenticationCode: _userauthentication.scssNaming: legacy

Authentication confirms that a person present in a procedure is who they say they are, by fingerprint or by the electronic route (Nafath). The block shows each attendee (photo, name, ID, rank) with an action to authenticate; Figma «Authentication» has the label, an electronic route, a manual route and an upload option.

Accessibility

  • Authentication buttons need clear text («مصادقة») in addition to the fingerprint icon.
  • Show the result of the check as text and a status tag, not only a color change.
  • The modal that captures the fingerprint must trap focus and return it to the button on close.

Notes for the owner

  • Class names mix casing (userauthenticAtionactionBg) and a typo (Disabeld); they are kept for compatibility. A renamed .moi-attendee-auth API would need owner approval.

RTL notes

  • The attendee block is a flex row, so photo and details swap sides in RTL automatically.
  • ID numbers stay left-to-right inside an isolated element so digits are not reversed.
