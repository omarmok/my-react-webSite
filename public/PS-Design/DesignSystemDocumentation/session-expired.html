Session Expired

Warn before a session ends and explain what happens next.

Pattern: Session ExpiredBuilt with: MoiSwal (SweetAlert2 + system theme)Last updated: November 2, 2026

Overview

Figma: Session ExpiredCode: MoiSwal (SweetAlert2 + system theme in sweet-alert.css)

A session timeout protects an account that was left open. The pattern warns before it happens, lets the user extend it, and explains what to do after it ends. It is shown with the system dialog (Sweet Alert); this page gives the wording and behavior from the Figma «Session Expired» frames.

Moments

MomentWhat the user seesActions
Warning«Your session is about to expire» with a countdown («You will be signed out in 8 seconds»)Extend session (primary) · Close
Expired«Please refresh the page. Don't worry, we kept all your data in place.»Refresh / sign in again

Live example

Code

const MoiSwal = Swal.mixin({ confirmButtonText: "تأكيد", cancelButtonText: "إلغاء", denyButtonText: "عدم الحفظ" });

MoiSwal.fire({
  title: "ستنتهي جلستك قريبا",
  html: 'سيتم تسجيل خروجك خلال <b>8</b> ثواني.',
  icon: "warning",
  timer: 8000,
  timerProgressBar: true,
  showCancelButton: true,
  confirmButtonText: "تمديد الجلسة",
  cancelButtonText: "اغلاق",
  didOpen: (el) => {
    const b = el.querySelector("b");
    const t = setInterval(() => (b.textContent = Math.ceil(Swal.getTimerLeft() / 1000)), 200);
    Swal.getPopup()._t = t;
  },
  willClose: (el) => clearInterval(el._t),
}).then((r) => { r.isConfirmed ? extendSession() : logout(); });

Rules

  • Warn at least 60 seconds before sign-out in real use; the 8-second countdown here is only for the demo.
  • Set the timeout by data sensitivity: shorter for case and identity data.
  • Auto-save forms so nothing is lost when the session ends.
  • Clear session data on the server; never rely only on the browser.
  • Redirect to sign-in with a clear reason, not a generic error.

Accessibility

  • The dialog must take focus and announce itself (SweetAlert2 sets role="dialog").
  • The countdown must not trap users: the extend button stays reachable and the timer can be extended with the keyboard.
  • WCAG 2.2.1: users must be able to extend a time limit.

RTL notes

  • SweetAlert2 mirrors the dialog and its button order with dir; the primary «Extend session» button stays on the start side.
  • Put the number in a <b> so the countdown digits are not reordered inside Arabic text.

Do & Don't

Do

  • Block the page behind the dialog and move focus into it.
  • Offer one clear action: sign in again.

Don't

  • Do not close the dialog by clicking outside; the user must act.
  • Do not lose unsaved input silently; warn before the session ends when possible.
