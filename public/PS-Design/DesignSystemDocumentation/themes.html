Themes (Light & Dark)

Semantic color tokens for the Light and Dark themes.

Source: Figma Themes388 tokensLast updated: November 2, 2026

Overview

Figma: 388 theme tokens (Light + Dark)Code: Light only

Figma keeps a Themes variable collection with two modes, Light and Dark: 388 semantic tokens grouped by purpose (Background, Text, Border, Form, Button, Link, Icon, Controls, Table, Stepper, Tag, Chip, Tooltip, Alpha, Charts). Components in Figma read these tokens, not raw colors. The compiled CSS has no dark theme yet (no prefers-color-scheme or data-theme rules), so Light values equal what ships today and Dark values are the design target.

Decision needed

  • Owner decision: ship Dark as CSS variables on [data-theme="dark"], or keep Dark as a Figma-only exploration.
  • If shipped, map each semantic token to a CSS custom property and migrate components group by group (Background and Text first).
  • Mixed-case names such as Alpha-primary-10 and typos (upcomming, boarder) are Figma names kept as-is; normalize them when the CSS names are created.
