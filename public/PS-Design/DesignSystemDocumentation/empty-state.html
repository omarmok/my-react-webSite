Empty State

No-data message for sections and tables, with the next step for the user.

المكوّن: الحالة الفارغة الملفات: _common.scss (.no-data), _table.scss (.nodataTable) آخر تحديث: 25 أكتوبر 2026

Purpose & when to use

Tells the user there is nothing to show yet and what to do. Figma: no-data (page ❖ Patterns / No Data Found) is the approved component; no-data-found is deprecated. Code: .no-data (cards, sections) and .nodataTable (inside a table).

Anatomy

ClassSpec
.no-data img120 × 80 illustration, centred
.no-data pSmall text, centred, margin-top $padding-md
.nodataTableColumn, centred, white; image 140px high; message h5

Usage rules

  • Write what happened and the next step («برجاء إجراء البحث لاستعراض البيانات»).
  • In a table keep header, settings bar (count 0) and pagination visible.
  • Images are decorative: alt="".

Developer API

<!-- Section / card -->
<div class="no-data">
  <img src="./images/no-data-found.svg" alt="">
  <p>لا توجد بيانات</p>
</div>

<!-- Inside a table -->
<tr><td colspan="6">
  <div class="nodataTable">
    <img src="./images/nodataavailable.png" alt="">
    <h5>برجاء إجراء البحث لاستعراض البيانات</h5>
  </div>
</td></tr>
