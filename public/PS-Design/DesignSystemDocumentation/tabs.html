Tabs

Tabs display several content sections in the same space, showing one section at a time. The project has two separate patterns, both layered on top of Bootstrap's native tabs (.nav-tabs / .tab-content).

المكوّن: التبويبات الملفات: _tabs.scss, _tabsDesign.scss آخر تحديث: 16 يوليو 2026

Purpose & when to use

Choose the pattern that fits the context: .create__tabs for circular icon-style tabs (e.g. record-creation steps), and .tabsDesign for a bordered card-style tab panel with text/table content.

Anatomy

Pattern 1: .create__tabs

Circular tabs (80×80) with a dashed border, layered on Bootstrap's native .nav-tabs.

Element Class Description
Root .create__tabs Root wrapper that applies the circular styling to the inner .nav-tabs .nav-link.
Active state .nav-link.active Solid background/border instead of dashed when active (standard Bootstrap class).
Disabled state .nav-link.disabled Lighter dashed border and a not-allowed cursor (standard Bootstrap class).

Pattern 2: .tabsDesign

A bordered tab panel with a light background, layered on Bootstrap's native nav and .tab-content.

Element Class Description
Root .tabsDesign Root wrapper.
Tab bar .tabsDesign nav The tab bar itself, with a light background.
Content panel .tab-content Tab content container, with a border and rounded corners.
Active pane .tab-content > .active The currently visible pane; displayed as flex with a white background and soft shadow.

Usage rules

  • Do not mix .create__tabs and .tabsDesign within the same tab group — each pattern is visually and structurally independent.
  • Use standard Bootstrap tab behavior (data-bs-toggle="tab") to switch panes; neither pattern has its own custom JavaScript behavior.

Accessibility Guidance

  • Follow standard Bootstrap/ARIA tab markup: role="tablist" on the nav, role="tab" on each link, role="tabpanel" on each pane, and aria-selected for the active state.
  • For the icon-only circular .create__tabs, add an aria-label or visually-hidden text describing each tab for screen reader users.

Developer API

The code samples below reflect the real structure in _tabs.scss and _tabsDesign.scss.

.create__tabs

<div class="create__tabs">
  <ul class="nav nav-tabs" role="tablist">
    <li class="nav-item" role="presentation">
      <button class="nav-link active" data-bs-toggle="tab" data-bs-target="#step1"
        type="button" role="tab" aria-selected="true">
        <img src="icon-1.svg" alt="" />
        <span>الخطوة 1</span>
      </button>
    </li>
    <li class="nav-item" role="presentation">
      <button class="nav-link" data-bs-toggle="tab" data-bs-target="#step2"
        type="button" role="tab" aria-selected="false">
        <img src="icon-2.svg" alt="" />
        <span>الخطوة 2</span>
      </button>
    </li>
  </ul>
</div>

.tabsDesign

<div class="tabsDesign">
  <nav>
    <div class="nav nav-tabs" role="tablist">
      <button class="nav-link active" data-bs-toggle="tab" data-bs-target="#overview"
        type="button" role="tab" aria-selected="true">نظرة عامة</button>
      <button class="nav-link" data-bs-toggle="tab" data-bs-target="#details"
        type="button" role="tab" aria-selected="false">تفاصيل</button>
    </div>
  </nav>
  <div class="tab-content">
    <div class="tab-pane active" id="overview" role="tabpanel">محتوى نظرة عامة</div>
    <div class="tab-pane" id="details" role="tabpanel">محتوى التفاصيل</div>
  </div>
</div>
