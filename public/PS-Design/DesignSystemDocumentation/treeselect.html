Tree Select (vue-treeselect)

Live examples and ready-to-copy code for vue-treeselect styled by the system: single, multiple, flat, field states, and inside a form.

المكوّن: القائمة الشجرية المكتبة: vue-treeselect 0.4.0 + Vue 2 آخر تحديث: 28 أكتوبر 2026

Single select

One value from a hierarchy. v-model holds the node id.

v-model: {{ value }}

<label class="form-label">الجهة</label>
<treeselect v-model="value" :options="options"
            placeholder="الرجاء الاختيار"
            no-results-text="لا توجد نتائج"
            no-options-text="لا توجد خيارات" />

Preselected value

Set v-model to an existing id; the branch is expanded to reveal it.

data: { value: "riyadh", options }

Multiple (tags)

multiple adds tags; value is an array of ids.

v-model: {{ value }}

<treeselect v-model="agencies" :multiple="true" :options="options"
            placeholder="الرجاء الاختيار" />
// agencies: ["naseem", "security"]

Flat mode

flat selects each node independently (selecting a parent does not select its children).

<treeselect v-model="units" :multiple="true" :flat="true" :options="options" />

Default expand level

default-expand-level opens the tree to the given depth when the menu opens.

<treeselect v-model="value" :options="options" :default-expand-level="2" />

Limit visible tags

limit and limit-text collapse extra tags into a counter.

<treeselect v-model="value" :multiple="true" :options="options"
            :limit="1" :limit-text="count => '+' + count" />

Not clearable, not searchable

clearable="false" hides the clear button; searchable="false" turns it into a pure picker.

<treeselect v-model="value" :options="options"
            :clearable="false" :searchable="false" />

Leaf-only selection

disable-branch-nodes allows picking only leaf nodes.

<treeselect v-model="value" :options="options" :disable-branch-nodes="true" />

Field states

Same state classes as Text Input: is-invalid, is-valid, is-warning, and disabled.

This field is required
<treeselect class="is-invalid" v-model="agency" :options="options" />
<div class="invalid-feedback d-block">هذا الحقل مطلوب</div>

<treeselect class="is-valid"   v-model="agency" :options="options" />
<treeselect class="is-warning" v-model="agency" :options="options" />
<treeselect v-model="agency" :disabled="true" :options="options" />

Inside a form (label, required, helper)

Label with .required, helper text under the field, and a validation state bound to the model.

Choose the agency responsible for the request
Please select an agency
<label class="form-label required">الجهة الأمنية</label>
<treeselect v-model="agency" :options="options"
            :class="{ 'is-invalid': touched && !agency }"
            @close="touched = true" />
<small class="form-text text-muted d-block mt-1">اختر الجهة المسؤولة عن الطلب</small>
<div class="invalid-feedback d-block" v-if="touched && !agency">يرجى اختيار الجهة</div>

Key props

PropDescription
v-modelSelected id (single) or array of ids (multiple)
optionsTree of { id, label, children }
multipleEnable multi-select with tags
flatDo not cascade selection to children
disabledDisable the control
clearable / searchableShow clear button / enable search
default-expand-levelDepth to expand on open
disable-branch-nodesOnly leaves are selectable
limit / limit-textCap visible tags and format the counter
placeholder / no-results-text / no-options-textArabic UI strings (pass them explicitly)

Setup

Load Vue 2 and vue-treeselect from libs, plus its stylesheet. System styling already lives in main.css (_vue-treeselect.scss).

<link href="./libs/tree-select/treeselect.css" rel="stylesheet" />
<script src="./libs/vue/vue-js.js"></script>
<script src="./libs/tree-select/tree-select.js"></script>

<script>
  Vue.component("treeselect", VueTreeselect.Treeselect);
  new Vue({
    el: "#app",
    data: {
      value: null,
      options: [
        { id: "moi", label: "وزارة الداخلية", children: [
          { id: "riyadh", label: "شرطة منطقة الرياض", children: [
            { id: "naseem", label: "مركز شرطة النظيم" },
            { id: "olaya",  label: "مركز شرطة العليا" }
          ] },
          { id: "security", label: "الإدارة العامة للأمن" }
        ] },
        { id: "makkah", label: "شرطة منطقة مكة المكرمة" }
      ]
    }
  });
</script>
