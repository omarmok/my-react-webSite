📒 Release notes

Every change made to the design system since January 2, 2023, newest first, mirroring the Figma log. Check it before starting work, and look for the “Dev” notes.

منذ: 2 يناير 2023 آخر تحديث: 26 أكتوبر 2026

رحلة تطوير النظام

Work on the design system began on January 2, 2023, with the design phase in Figma; the code repository was created the following day. Since then the project has followed two parallel tracks, designing in Figma and converting the designs to code, until the core decisions on tables, buttons, colors and components were settled. Each phase brought improvements and additions in line with business requirements and platform needs.

  • Design first: each component is designed in Figma, then converted to code.
  • Review with developers: the designs are confirmed with the developers to make sure they are correct.
  • Iteration until stable: some components, such as the Person Card, were rebuilt more than once (up to three times) until the decision was settled.

How to read it

  • Page or feature: the component that changed in Figma (same name as its page).
  • Version: shown only for versioned components (e.g. Buttons, File Uploader); otherwise “—”.
  • Dev: the orange box means developers must act (e.g. replace a property or a removed variant).
  • Related: the masters or properties touched by the change.

To add an entry, put a new object at the top of the array in js/changelog-data.js using the same fields; the page updates automatically.
