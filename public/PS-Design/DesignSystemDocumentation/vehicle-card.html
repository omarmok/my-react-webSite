Vehicle Card

A vehicle summary used in inquiries and case records.

Component: Car ComponentFiles: _vehiclemodal.scssLast updated: November 2, 2026

Overview

Figma: moi-vehicle-cardCode: legacy, page-scoped

The vehicle card summarizes a vehicle in inquiry results and case records: plate, make and model, status and key registration data. Figma «Business Components / Car Component» also holds car-info, carComponent (statistics) and owner/user/details blocks, plus a weapon component built on the same pattern.

What exists in code

  • No shared .moi-vehicle-card class yet. Vehicles render with the legacy page-scoped card .newIms--inquiryDs--card (see Inquiry/car.html): header with image and status, body with read-only fields.
  • Related vehicles table: #vehicleModal .relatedVecielsTableSeetings and .tablecontainer .table in _vehiclemodal.scss (hard-coded #f4f5fb, #e6e8f0, red that should become tokens).
  • Until a shared class is approved, build new screens from the system pieces: Card + Tags + read-only fields.

Accessibility

  • Plate numbers mix Arabic and Latin letters: render them in an isolated <bdi> so the order is not scrambled in RTL.
  • Status such as «wanted» must be text, not color only.
  • Read-only fields should use readonly rather than disabled so they stay readable and focusable.

RTL notes

  • Plate numbers mix directions: wrap them in <bdi>, and keep Latin letters and digits in the order printed on the plate.
  • Field labels and values align to the start side in both languages.
