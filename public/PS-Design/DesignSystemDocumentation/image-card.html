Image Card

An attached image with a caption and an optional action.

Component: Image CardFiles: _common.scss (.imagecard)Last updated: November 2, 2026

Overview

Figma: imageCard-V2Code: legacy classes in _common.scss

A card that shows an attached image with a short caption and an optional round action (for example, mark as main). Used for evidence photos and attachments. In code it is the .imagecard block in css/common/_common.scss; it still uses hard-coded colors (#e2b785, #4caf50) that should move to tokens.

Accessibility

  • Give the image a meaningful alt; the caption alone is not enough for people who cannot see it.
  • The action button needs an aria-label because it only has an icon.
  • Clip long captions with care: keep the full text available (title or detail view).

Do & Don't

Do

  • Use one aspect ratio for images in the same grid.
  • Keep captions to two short lines.

Don't

  • Do not stretch images: the card crops with object-fit: cover.
  • Do not place several action buttons on one image.

RTL notes

  • The action button uses a physical left offset, so it stays on the left in both directions; keep it there for consistency.
  • Caption text follows the page direction.
