Tooltip

Short dark label for icon-only actions and truncated values, top or bottom.

المكوّن: التلميح الملفات: _tooltip.scss آخر تحديث: 25 أكتوبر 2026

Purpose & when to use

A short dark label that explains an icon-only button or shows a truncated value. Code: css/components/_tooltip.scss (CSS-only .moi-tooltip or Bootstrap tooltip with customClass: "moi-tooltip"). Figma: tooltip, Position = Top | Bottom.

  • Never put required information only in a tooltip.

Anatomy

PartSpec
BubbleBackground $Neutral-900, white text font-sm-400, padding $padding-sm $padding-lg, radius $radius-md, max-width 240px
Arrow12 × 6, same colour, centred
Positiondata-placement="top" (default) or "bottom"
TriggerShows on hover and keyboard focus (.moi-tooltip-wrap:focus-within); respects reduced motion

Developer API

<!-- CSS only -->
<span class="moi-tooltip-wrap">
  <button class="moi-btn--text-icon" aria-describedby="tip-1" aria-label="تفاصيل">…svg…</button>
  <span class="moi-tooltip" id="tip-1" role="tooltip" data-placement="top">عرض التفاصيل</span>
</span>

<!-- Bootstrap tooltip -->
<button data-bs-toggle="tooltip" data-bs-title="عرض التفاصيل">…</button>
<script>
  document.querySelectorAll('[data-bs-toggle="tooltip"]').forEach(el =>
    new bootstrap.Tooltip(el, { customClass: 'moi-tooltip' }));
</script>
