Inquiry Person

Look a person up and read the result at a glance.

Pattern: Inquiry PersonFiles: _personInquiry.scssLast updated: November 2, 2026

Overview

Figma: Inquiry Person patternCode: _personInquiry.scss

The inquiry pattern lets an officer look a person up and read the result at a glance: photo, name, ID, whether the person is wanted, and the next actions. It is built from the Person Card, Tags and Buttons, plus the inquiry classes below (css/components/_personInquiry.scss). A matching vehicle inquiry exists; see the Vehicle Card.

Flow

  • Enter ID or name, then press search (Enter works).
  • While searching, show a loading state; do not clear the previous result until the new one arrives.
  • If nothing matches, show the empty state (Empty State) with a way to change the query.
  • A wanted person must be unmistakable: the red banner plus text, never color alone.

Accessibility

  • Announce the result count in an aria-live="polite" region.
  • Photos need alt with the person's name.
  • Keep action buttons reachable by keyboard in a logical order.

RTL notes

  • Result cards and detail blocks mirror with the page direction; the wanted banner spans the full width in both.
  • ID and plate values stay left-to-right inside <bdi>.
