Checkbox

Turn one option on or off, or choose several from a list.

Component: CheckboxFiles: _checkbox.scssLast updated: November 2, 2026

Overview

Checkbox: in codeRadio: page-scoped only, needs owner approval

A checkbox lets the user turn one option on or off, or pick several options from a list. It is styled on top of Bootstrap's .form-check-input in css/common/_checkbox.scss, and matches the Figma «Checkbox» component (16×16, radius 4, 2px border; Unchecked / Checked / Mixed × Default / Disabled / Focused).

Anatomy

  • Box — .form-check-input, 16×16.
  • Label — .form-check-label, always present and linked with for.
  • Wrapper — .form-check keeps box and label on one line.

Radio status

There is no shared radio component yet. The only radio style in the project (label.radio with input[type="radio"]) is scoped inside #Accidents in css/common/_common.scss. A previous attempt to centralize it with a new wrapper class was reverted, because adding a public class needs the owner's approval. Until then, do not copy the scoped style into other screens: ask for a shared Radio.

Accessibility

  • Every box needs a visible label connected with for/id; clicking the label toggles the box.
  • Keyboard: Tab moves between boxes, Space toggles. The focus ring appears for keyboard users only (:focus-visible).
  • Group related boxes in a fieldset with a legend.
  • Mixed state is visual only: also expose the real state (for example, a count) to screen readers.

Do & Don't

Do

  • Use a checkbox for independent yes/no choices and multi-select lists.
  • Write the label so it reads as a true statement when checked.

Don't

  • Do not use a checkbox when only one option may be chosen.
  • Do not hide the label or rely on color alone.

RTL notes

  • The box sits at the start side of the label, so it appears on the right in Arabic; the layout mirrors with dir, no extra class.
  • The tick and dash are symmetrical and are not mirrored.
